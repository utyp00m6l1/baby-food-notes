# 产科护士：不平凡的坚守

> 更新时间：2026-09-11 (UTC+8)

【昆明电视台春城频道8099999特别策划】不平凡的坚守，向所有辛勤的劳动者们致敬！

今天我们要说的是一位白衣天使，她就是昆明市妇幼保健院，有着22年产科经验的产前科护士长方丽萍，接下来就让我们一起来看看白衣天使们日常的故事。

 

上午九点半，方丽萍正在和病房内的产妇交流情况，这已经是今早七点半上班以后，方丽萍的第二次巡查房了，这样的巡查工作在一天的工作中要反复很多次，别看产前科只有5个病房28张床位，可一趟巡查下来最少也需要一个多小时，而且对于一些情况特殊的产妇，尤其要细心对待，反复叮咛。

 

**昆明市妇幼保健院产前科护士长 ****方丽萍：**一个是在巡视过程中，对夜班护士上班情况要有个了解，夜班入夜的产妇大概是个什么情况，如果有宫缩的肯定要询问，还有一些高血压的孕妇晚上的睡眠情况。

 

说起自己负责科室的孕产妇情况，方丽萍总是滔滔不绝，她不仅仅需要事无巨细的掌握每一位产妇的情况，还要了解产妇和家属的需求、病房内的电器、消防、卫生、清洁等各种细节也都在她的工作范围内。

 

**昆明市妇幼保健院产前科护士长 ****方丽萍：**每天有些什么特殊情况，几月几号有什么情况都记在本子上，说好记性不如烂笔头，不是有人说，护士长其实就是一个大管家。

 

除了产科病房外，产房也是方丽萍繁忙工作的主要场所，这个在外人看来有些神秘的地方对于方丽萍来说更像是一个温馨的家，因为在这里她和同事们要像亲人一样耐心安慰马上就要临盆的孕妇，给他们鼓励，以最好的状态迎接小生命的到来。

 

**昆明市妇幼保健院产前科护士长 ****方丽萍：**主要是鼓励他们，因为产妇在陌生环境内肯定是紧张的。

 

每天，方丽萍就这样一趟一趟奔波在科室的病房和产房之间，繁忙的“大管家”细致的照看着科室内的方方面面，在产妇的眼里方护士长就是一颗温暖的“定心丸”。

 

**产妇：**比较关心细心的感觉，随时询问我们的情况。

 

**产妇家属：**护士长也好，医生也好都是态度很好，很温馨。

 

从1995年参加工作到如今，22年里在方丽萍手中出生的新生儿数以万计，虽然这些产妇们不一定全都记得这位曾经帮助过他们的产科“大管家”，但每一位健康出生的宝宝都是方丽萍和同事们的骄傲。

 

**昆明市妇幼保健院产前科护士长 ****方丽萍：**你看这些都是在我们妇幼保健院诞生的宝宝，你看我们这个本子上（家长留言），他们最直白的一个心理。

 

翻看着手中的产妇和家属的留言，方丽萍护士长的脸上满满都是自豪的微笑，相比起让自己引以为傲的工作，面对家庭时心中难免有些愧疚，因为护士这份职业的特殊性，作为妻子和妈妈的自己很少有时间陪伴家人。

 

**
**

**昆明市妇幼保健院产前科护士长 ****方丽萍：**并不能说是下班八小时以后就完了 我们手机24小时都要开机，都要听班（待命）。

 

虽然日常的工作非常辛苦，但是方丽萍无怨无悔，因为这是她作为一名医务工作者的职责，她会一直坚守下去。

 

**昆明市妇幼保健院产前科护士长 ****方丽萍：**就是职责所在吧，也非常感谢我身边有一个很优秀的团队，大家都是这样努力工作，只要母婴平安开心出院，我们所有辛苦都是值得的。
