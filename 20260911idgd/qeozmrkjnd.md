# 【妇产科普】红肿、发烧、化脓！宝宝的这些反应正常吗？

> 更新时间：2026-09-11 (UTC+8)

按照北京市免疫规划疫苗免疫程序（2021版），宝宝出生后都必须按照免疫规划程序接种疫苗，每个宝宝从出生到6周岁 **至少**要接种23剂次疫苗！ 

由于存在个体差异， **个别宝宝接种完疫苗后可能出现不良反应。**

那出现不良反应后该怎么办？听我细细讲来~

**接种疫苗后**

# 

**可能出现哪些不良反应？**

# 

**最常见的****是一般反应**，是由疫苗本身所固有的特性引起的，不会造成宝宝机体生理和功能损害，包括：

**局部反应**

接种疫苗后12~24小时接种部位出现红、肿、热、痛，一般2-3天消退。

**全身反应**

发烧（少数人在接种疫苗后8－12小时体温升高，一般在38.5℃以下）、 烦躁、易惹哭、睡觉不踏实、 食欲减退、 腹泻、呕吐、 嗜睡、 皮疹（但较轻微）等。

**其次是偶合反应**，指的是接种疫苗时，儿童正处于一种疾病发病的潜伏期，接种后刚好发病，属于巧合，与接种疫苗无关。

**孩子打疫苗有了不良反**

# 

**应该怎么办？**

# 

对于一般反应，一般无需特殊处理，注意休息，多饮水、保暖，防止继发其他疾病，1~2天这些反应就会自动消失。

**体温低于38.5℃**， 加强观察，物理降温，多饮水，注意休息即可； **体温达到或高于38.5℃**，可服用退烧药，一般1~2天消退。若1~2天发热不退或发热≤38.5℃并伴有其他全身症状、异常哭闹等，应及时去医院就诊。

对于接种部位局部的红肿、硬结，48小时内可热敷促进消退。

对于 偶合反应，应及时到医院就诊。 

**接种卡介苗后的**

# 

**特殊反应**

# 

接种卡介苗后约一至二周，局部会呈现红肿、化脓、小溃疡，一般8-12周结痂/留疤，偶可出现一过性发热， 1-2天后自行缓解，如果持续发热（38℃）或发热超过72小时要及时就医。

接种卡介苗后局部有脓泡或溃烂时，不必擦药或包扎。但局部要保持清洁，衣服不要穿得太紧，如有脓液流出，可用无菌纱布或棉花拭净，不要挤压，平均约两至三个月自然会愈合结痂，痂皮要等它自然脱落，不可提早把它抠去。

不良反应不可怕，只要科学认识正确处理，都能顺利度过，愿每个宝贝都能安全接种！
