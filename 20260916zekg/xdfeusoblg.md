# 武汉市第一医院高分通过湖北省重点实验室建设认证

> 更新时间：2026-09-16 (UTC+8)

****
2月10日，依托武汉市第一医院建设的“皮肤感染和免疫湖北省重点实验室”以93.5分的成绩高分通过湖北省科技厅组织的建设认证。著名皮肤病学、中国工程院廖万清院士领衔的9位全国皮肤病领域专家“天团”参与了现场认证并对实验室给予了高度评价。

皮肤是人体的最大器官，是重要的物理屏障和免疫屏障。21世纪以来，机会性病原菌感染的发病率呈逐年上升趋势，感染耐药问题突出，以银屑病、系统性红斑狼疮等为代表的免疫性皮肤病，因慢性、复发、病因复杂严重影响着患者的生活质量和身心健康。

去年11月底，武汉市政府印发《武汉市推进市区级医院特色化发展实施方案》，要求公立医院坚持公益性导向，按照“一院一特色”“一院一策”的原则和“强专科大综合”的发展思路，在专科领域提高诊疗服务、临床研究及成果转化能力，高质量推进医院特色化发展，力争到2025年，全市建成一批全国排名靠前、综合实力强劲、专科特色鲜明、品牌效应凸显的高水平、现代化医院。按《方案》要求，市第一医院在皮肤科方向进行特色化建设。

围绕这一目标，武汉市第一医院持续擦亮皮肤科这块“金字招牌”，统筹门诊、住院、科研教学、互联网医院等集约化管理，积聚资源要素，正在以院中院模式高质量打造“武汉市皮肤病医院”。建设皮肤感染和免疫湖北省重点实验室正是该院在临床诊疗基础上补齐科研短板，提升科技创新能力的一项重要举措。

// 中科院院士廖万清正在向工作人员了解实验室建设情况。
据了解，实验室主要定位于皮肤感染和免疫疾病的致病机制及免疫机制的基础研究与应用研究，探索疾病治疗新靶点，搭建技术创新平台，开展中西医结合和多学科交叉在皮肤感染和免疫疾病中应用发展的新模式。

// 廖万清院士（右一）带领9位全国皮肤病领域顶尖专家了解实验室建设情况。
我国著名皮肤病学、医学真菌学专家、中国工程院廖万清院士领衔，中南大学副校长、湘雅医学院院长陈翔教授，华中科技大学同济医学院副院长鲁友明教授，湖北中医药大学副校长王平教授，皮肤与免疫疾病国家临床医学研究中心主任、北京大学第一医院李若瑜教授，中华医学会皮肤性病学分会候任主委、中国医科大学附属第一医院副院长高兴华教授等9名全国皮肤病领域顶尖专家组团来到武汉市第一医院，参加皮肤感染和免疫湖北省重点实验室建设认证会。湖北省科技厅副厅长杜耘、武汉市卫生健康委副主任郑云及有关部门同志参加了会议。

★ 成立于1927年的**武汉市第一医院皮肤科**是湖北省乃至华中地区知名的“老字号”，也是医院的“金字招牌”。科室年均服务皮肤病患者逾120万人次，开展皮肤外科手术近1.1万台次，医疗服务量位居全国前列。现已建设成为国家区域中医（专科）诊疗中心、国家临床重点专科、国家中医药重点学科、国家中医药重点专科协作组组长单位，入围全国罕见病诊疗协作网，实现了国家级重点专学科建设“大满贯”。★ **武汉市第一医院皮肤科实验室**成立于20世纪80年代初，是国内较早设立皮肤真菌、免疫和病理实验室的皮肤科。自2007年创建湖北省感染性皮肤病临床医学研究中心以来，实验室得到进一步发展，现已建成华中地区规模最大的皮肤病数据库、感染性皮肤病标本库和形态库。

武汉市第一医院党委书记、院长魏力表示，医院将进一步推进皮肤感染和免疫湖北省重点实验室高水平建设，培育科技创新团队，强化基础研究和成果转化，加快打造国内一流皮肤病院中院，积极为湖北地区乃至全国皮肤病防治、科技进步等方面作出基础性和前瞻性贡献。
